# ข้อจำกัดของระบบ (Known Limitations)

ระบบรุ่นที่ส่ง (ส่งงาน 2026-11-09) ยังไม่มีความสามารถต่อไปนี้  
แต่ละข้อมี User Story รออยู่ใน [Product Backlog](./requirements.md)

เมื่อปิด story ที่เกี่ยวข้อง ให้ลบข้อนั้นออกจากไฟล์นี้ใน PR เดียวกัน

## บัญชีผู้ใช้

- **ไม่ยืนยันว่าเป็นเจ้าของอีเมลจริง**: ตอนสมัครระบบตรวจแค่รูปแบบ `<รหัสนักศึกษา>@student.tu.ac.th` ใครรู้รหัสของเพื่อนก็สมัครแทนได้ ระบบยังไม่ส่งอีเมลใดๆ (`MAILERS` ตั้งเป็น console backend ซึ่งพิมพ์อีเมลลง terminal) (US-14, SP-2)
- **ศิษย์เก่าเข้าระบบไม่ได้หลังอีเมลมหาวิทยาลัยถูกปิด**: ยังผูกอีเมลส่วนตัวกับบัญชีไม่ได้ (US-15)
- **ผู้ใช้ลบบัญชีของตัวเองไม่ได้**: `User.anonymize()` มีแล้ว แต่ยังไม่มีหน้าให้กดเอง ผู้ดูแลต้องเรียกจาก Django shell ให้ (US-13)
- **ระงับผู้ใช้ได้แค่ปิด `is_active` ในฐานข้อมูล**: ไม่มีเหตุผล ระยะเวลา หรือบันทึกว่าใครระงับ (US-16)

## ภาควิชา รุ่น และรายวิชา

- **ไม่มีการนำเข้าไฟล์จำนวนมาก**: เอกสารเดิมของ CN21–CN25 ต้องอัปโหลดผ่านฟอร์มทีละไฟล์ (US-17)
- **รุ่นจุดตัดของข้อสอบรุ่นเก่ามีค่าเดียวทั้งระบบ** (`legacy_batch_max` = 23) ใช้กับทุกภาค แม้เลขรุ่นของแต่ละภาคเริ่มคนละปี (US-18)
- **อัปโหลดวิชาที่ยังไม่ผูกกับรุ่นไม่ได้** และไม่มีช่องทางขอให้ Super Admin เพิ่มวิชา (US-19)
- **ระบบไม่รู้ว่าผู้ใช้อยู่รุ่นไหน**: ยังไม่มีกฎจับคู่ปีเข้ากับเลขรุ่นของแต่ละภาค (US-20)

## เอกสาร

- **แก้ไขหลังอัปโหลดไม่ได้**: เจ้าของส่งเวอร์ชันใหม่ แก้คำอธิบาย หรือลบเอกสารของตัวเองไม่ได้ ถ้าต้องแก้ต้องอัปโหลดเป็นเอกสารใหม่ (US-21)
- **ไม่กันไฟล์ซ้ำและไม่สแกนไวรัส**: ระบบตรวจแค่ MIME และ magic bytes `%PDF-` เก็บ `sha256` ไว้แต่ไม่ได้ใช้กันไฟล์ซ้ำ และ `scan_status` ค้างเป็น `pending` ตลอด PDF ที่ฝัง JavaScript จึงผ่านได้ ด่านที่มีคือ Moderator ตรวจก่อนเผยแพร่ (US-12 กันไฟล์ซ้ำ, US-24 สแกนไวรัส, SP-1)
- **ไม่มีหน้ารวมข้อสอบรุ่นเก่า** ให้ Super Admin ตรวจหรือเอาลงหลังเผยแพร่แล้ว (US-27)

## การค้นหา

- ค้นได้ด้วยรหัสวิชาแบบตรงตัวเท่านั้น ไม่มีแท็กหรือค้นจากหัวข้อ (US-23)
- ผลค้นหาเรียงตายตัว ภาค → รุ่น → ใหม่สุด เรียงตามยอดดาวน์โหลดหรือคะแนนไม่ได้ และระบบยังไม่นับยอดดาวน์โหลด (US-28, US-8)

## ชุมชนและการร้องเรียน

- ไม่มีคอมเมนต์ การให้ดาว หรือรีวิว (US-29, US-30, US-31)
- **ไม่มีช่องทางร้องเรียนในระบบ**: ไม่มีปุ่มรายงานเอกสาร ไม่มีแบบฟอร์มให้เจ้าของลิขสิทธิ์ที่ไม่มีบัญชีแจ้งลบ และไม่มีขั้นตอนให้ Super Admin ตัดสินเรื่องร้องเรียน (US-32, US-33, US-35)

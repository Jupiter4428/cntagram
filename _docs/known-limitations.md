# ข้อจำกัดของระบบ (Known Limitations)

ระบบรุ่นปัจจุบันบน Production ([https://cntagram-h195.onrender.com/](https://cntagram-h195.onrender.com/)) มีข้อจำกัดและขอบเขตที่ไม่ได้รวมอยู่ในระบบดังนี้

## บัญชีผู้ใช้

- **ไม่ยืนยันว่าเป็นเจ้าของอีเมลจริง**: ตอนสมัครระบบตรวจแค่รูปแบบ `<รหัสนักศึกษา>@student.tu.ac.th` ใครรู้รหัสของเพื่อนก็สมัครแทนได้ ระบบยังไม่ส่งอีเมลยืนยัน (`MAILERS` ตั้งเป็น console backend ซึ่งพิมพ์อีเมลลง terminal)
- **ศิษย์เก่าเข้าระบบไม่ได้หลังอีเมลมหาวิทยาลัยถูกปิด**: ยังไม่มีหน้าผูกอีเมลส่วนตัวกับบัญชี
- **ระงับผู้ใช้ได้แค่ปิด `is_active` ในฐานข้อมูล**: ไม่มีเหตุผล ระยะเวลา หรือบันทึกว่าใครระงับ
- **การจำกัดอัตราการเข้าสู่ระบบร่วมกันหลัง IP/NAT เดียวกัน (Shared IP Rate Limiting)**: ถัง IP ของ Two-bucket login rate limit นับความล้มเหลวรวมจาก IP เดียวกัน 100 ครั้งต่อ 5 นาที (`LOGIN_RATE_LIMIT_IP_ATTEMPTS = 100`) เพื่อป้องกันการโจมตีแบบ Password Spraying ข้ามบัญชี หากมีการพยายามเข้าสู่ระบบผิดเกิน 100 ครั้งจาก IP เดียวกัน ผู้ใช้ทุกคนที่อยู่หลัง IP นั้น (เช่น Wi-Fi หรือ NAT ของมหาวิทยาลัย) จะได้รับ HTTP 429 ชั่วคราว แม้จะใส่รหัสผ่านถูกต้องก็ตาม จนขึ้นช่วง 5 นาทีถัดไป (รอไม่เกิน 5 นาที)
  ข้อแลกเปลี่ยน: เพดาน 100 ทำให้ IP เดียวเดารหัสข้ามบัญชีได้มากกว่าเดิม 5 เท่า และเพราะนับเป็นช่วงเวลาคงที่ (fixed window) ช่วงที่คร่อมขอบเวลาจะเดาได้สูงสุด 2 เท่าของเพดาน (บัญชีเดียว 10 ครั้ง, IP เดียว 200 ครั้ง)

## ภาควิชา รุ่น และรายวิชา

- **รุ่นจุดตัดของข้อสอบรุ่นเก่ามีค่าเดียวทั้งระบบ** (`legacy_batch_max` = 23) ใช้กับทุกภาค แม้เลขรุ่นของแต่ละภาคเริ่มคนละปี
- **อัปโหลดวิชาที่ยังไม่ผูกกับรุ่นไม่ได้** และไม่มีช่องทางขอให้ Super Admin เพิ่มวิชาผ่านหน้าเว็บของนักศึกษา
- **ระบบไม่คำนวณเลขรุ่นของผู้ใช้อัตโนมัติ**: ยังไม่มีกฎจับคู่ปีเข้าศึกษากับเลขรุ่นของแต่ละภาค

## เอกสารและการจัดเก็บไฟล์

- **ไม่สแกนไวรัส**: ระบบตรวจแค่ MIME, magic bytes `%PDF-` และตรวจไฟล์ซ้ำด้วย SHA-256 ส่วน `scan_status` ค้างเป็น `pending` ตลอด PDF ที่ฝัง JavaScript จึงผ่านได้ ด่านที่มีคือ Moderator ตรวจก่อนเผยแพร่
- **Ephemeral Filesystem บน Render Free Tier**: การรันบน Render Free Plan ไม่มี Persistent Disk ทำให้ไฟล์ PDF ที่อัปโหลดไว้ใน `media/vault/` จะถูกล้างเมื่อคอนเทนเนอร์ Redeploy หรือหมุนรอบใหม่ (แม้แถวข้อมูลใน PostgreSQL ยังอยู่) ดูรายละเอียดใน [ADR 0005](./adr/0005-production-deployment-and-backup.md) และ [`backup-operations.md`](./backup-operations.md)

## การค้นหาและชุมชน

- **การค้นหา**: ค้นได้ด้วยรหัสวิชาแบบตรงตัว (พร้อมตัวกรองภาควิชา รุ่น ประเภทเอกสาร ช่วงสอบ และปี พ.ศ.) แต่ยังไม่มีแท็กหรือค้นจากหัวข้ออิสระ และผลค้นหาเรียงตายตัว (ภาค → รุ่น → ใหม่สุด) ยังเรียงตามยอดดาวน์โหลดไม่ได้
- **คอมเมนต์และให้คะแนนใต้เอกสารโดยตรง**: ไม่มีคอมเมนต์หรือการให้ดาว 1–5 ดาวใต้หน้าเอกสารแต่ละชิ้นโดยตรง (ใช้กระดานสนทนาเว็บบอร์ด `webboard` ที่ผูกกับรายวิชาได้ และ Shoutbox / โพลหน้าแรกแทน)
